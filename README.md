# 🦜 Parrot

会議の録音から、そのまま文字起こしを作るアプリです。ボタン1つで録音し、15分ごとに自動で文字起こしして、Word（.docx）やマークダウン（.md）で保存できます。録音済みの音声ファイルから文字起こしすることもできます。

## 使い方

1. ページを開き、右上の「設定」からGemini APIキーを保存します（初回だけ）。
   - APIキーは [Google AI Studio](https://aistudio.google.com/apikey) で無料で作れます。
2. 赤いボタンを押して録音開始、もう一度押して停止します。
   - 録音済みの音声（m4a・mp3・wav など）は「録音済みの音声ファイルから文字起こし」から選びます。
3. 文字起こしが終わったら、必要に応じて話者名を置き換え、「Word（.docx）で保存」などで保存します。

## iPhoneで使う

- Safariでこのページを開き、共有ボタン →「ホーム画面に追加」で、アプリのように使えます（ホーム画面から開いたときは、APIキーをもう一度だけ入力してください）。
- iPhoneでは、録音中に画面を消したりほかのアプリに切り替えたりすると録音が止まります。長い会議は「ボイスメモ」で録音し、ボイスメモの共有ボタン →「"ファイル"に保存」してから、Parrotで「録音済みの音声ファイルから文字起こし」を選ぶのがおすすめです。

## 注意

- パソコンではChromeで使ってください。録音中はタブを閉じたり、PCをスリープさせたりしないでください。
- APIキーと記録は、使っている人のブラウザの中にだけ保存されます。
- Geminiの無料枠では、送った音声や文字がGoogleのサービス改善に使われる場合があります。会議の内容に応じて判断してください。
- お支払い（Billing）を設定していないAPIキーなら、料金はかかりません。
